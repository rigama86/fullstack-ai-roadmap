# 🧩 ¿Qué es n8n?

n8n es una plataforma de automatización de workflows.

Permite conectar:

```
Aplicación A

      |

    n8n

      |

Aplicación B
```

Ejemplos:

```
Google Sheets

      |

n8n

      |

OpenAI

      |

Email
```

---

# 📚 Conceptos fundamentales

# 1. Workflows

Un workflow representa un proceso automatizado.

Ejemplo:

```
Nuevo usuario registrado

        |

Enviar datos a IA

        |

Generar mensaje personalizado

        |

Enviar correo
```

---

# 2. Nodes

Los nodos representan acciones dentro del flujo.

Ejemplos:

- HTTP Request.
- Webhook.
- Database.
- OpenAI.
- Email.
- Slack.
- Google Services.

Ejemplo:

```
Trigger

  |

OpenAI Node

  |

Database Node

  |

Notification Node
```

---

# 3. Triggers

Los triggers inician automatizaciones.

Ejemplos:

## Evento

```
Nuevo registro
```

## Tiempo programado

```
Cada día a las 8 AM
```

## Webhook

```
Sistema externo

      |

     n8n
```

---

# 4. Integración con APIs

n8n permite conectarse con servicios externos:

- REST APIs.
- GraphQL.
- Webhooks.
- Bases de datos.

Arquitectura:

```
Sistema externo

      |

     API

      |

     n8n

      |

Proceso automático
```

# 🤖 Agentes de IA

Un agente combina:

```
LLM

 +

Memoria

 +

Herramientas

 +

Acciones
```

Ejemplo:

```
Usuario:

"Analiza mis ventas y genera un reporte"


Agente:

1. Consulta base de datos

2. Analiza información

3. Genera reporte

4. Envía resultado
```

---

# 🔌 MCP (Model Context Protocol)

MCP permite conectar modelos de IA con herramientas externas de forma estandarizada.

Conceptualmente:

```
Modelo IA

     |

MCP

     |

Herramientas

 ┌───────────────┐
 │ APIs          │
 │ Archivos      │
 │ Bases datos   │
 │ Servicios     │
 └───────────────┘
```
