# 🚀 Objetivo del curso

Aprender a crear aplicaciones modernas utilizando Inteligencia Artificial Generativa dentro de una arquitectura Full Stack.

La meta es pasar de consumir APIs tradicionales a construir aplicaciones capaces de:

- Generar contenido.
- Conversar con usuarios.
- Analizar información.
- Automatizar tareas.
- Crear asistentes inteligentes.

---

# 🎯 ¿Por qué aprender Angular + NestJS + OpenAI?
