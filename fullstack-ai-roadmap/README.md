# 📖 Acerca del proyecto

Este repositorio documenta una ruta de aprendizaje enfocada en el desarrollo **Full Stack** utilizando tecnologías modernas como **Angular**, **NestJS**, **Docker** e **Inteligencia Artificial Generativa**.

El objetivo es proporcionar una guía clara para aprender desde los fundamentos hasta el desarrollo de aplicaciones empresariales, integrando APIs de IA, agentes inteligentes y arquitecturas escalables.

---

# 🎯 Objetivos

- Aprender Angular desde cero hasta un nivel profesional.
- Construir APIs REST con NestJS.
- Contenerizar aplicaciones con Docker.
- Diseñar arquitecturas basadas en microservicios.
- Integrar modelos de IA mediante OpenAI.
- Desarrollar agentes inteligentes con LangChain y LangGraph.
- Automatizar procesos utilizando n8n y MCP.
- Crear proyectos reales para fortalecer las habilidades adquiridas.
